# PHENOMEN Store

Мультитенантная платформа магазинов: сервер (Node.js + Express + PostgreSQL),
браузерная админка (React + Vite) и мобильное приложение (Expo).

## Запуск

```bash
npm install
cp .env.example .env
npm run dev
```

Конфиг один — `.env` в корне репозитория, общий для сервера и клиентов.
`server/.env` и `client/.env` заводить нельзя.

## Учётки для разработки

Значения берутся из `.env`, в репозиторий реальные пароли не попадают.

| Роль | Переменные | Где входить |
| --- | --- | --- |
| Супер-админ платформы | `PLATFORM_ADMIN_LOGIN` / `PLATFORM_ADMIN_PASSWORD` | `/login` в админке, вкладка «Платформа» в приложении |
| Владелец демо-магазина | `DEMO_OWNER_LOGIN` / `DEMO_OWNER_PASSWORD` | `/shop/login` |

Локально удобно ставить `km` / `123` — эти значения используются в описаниях
задач. Демо-владелец создаётся только вне production и только если переменные
заданы. Супер-админ может войти в кабинет любого магазина через кнопку входа в
списке магазинов (impersonation).

## Код для входа

Покупатель входит по адресу почты: `POST /auth/code` присылает четырёхзначный
код письмом, `POST /auth/verify` его проверяет. Отправка настраивается
переменными `SMTP_*` в корневом `.env`. Пока `SMTP_HOST` и `SMTP_FROM` пусты,
письмо не уходит, а код возвращается в ответе и виден в приложении — это режим
разработки. Вне production код приходит в ответе всегда, в production — только
письмом.

## Картинки

`POST /media/upload` возвращает относительный путь `/uploads/<tenant>/<файл>`.
Клиенты подставляют к нему адрес API через `resolveMediaUrl`, поэтому один и тот
же товар открывается и в браузере, и на телефоне. Чтобы телефон видел картинки,
`EXPO_PUBLIC_API_URL` должен указывать на адрес машины в локальной сети, а не на
`localhost`.

## Телефон по USB

Metro Expo пробрасывает себе порт 8081 сам, а порт API — нет. Если приложение
открывается, но данные не грузятся с сообщением «Нет связи с интернетом»,
проброс 4000 не применился (телефон подключили позже запуска или переткнули
кабель). Лечится без перезапуска всего:

```bash
npm run reverse
```

`EXPO_PUBLIC_API_URL` при работе по USB обязан быть `http://localhost:4000` —
телефон ходит на свой localhost, а adb перекидывает его на машину. Адрес вида
`192.168.x.x` нужен только при запуске по Wi-Fi (`npm run dev:wifi`), где
проброса нет. Значение попадает в бандл при старте, поэтому после правки `.env`
нужен перезапуск Expo с очисткой кэша:

```bash
npx expo start --localhost -c
```

В режиме разработки экран ошибки показывает адрес, по которому приложение
пыталось достучаться — по нему сразу видно, тот ли он.
